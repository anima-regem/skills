# Shared optional inputs

- `watcher.glb` is a skinned humanoid with a relaxed standing action. It combines two files in the same CC0 v1.0 release, `KinemIQ_Mannequin.glb` and `GLB/Idle_relaxed.glb`, using their matching joint names. [KinemIQ CC0 release](https://github.com/Kinemiq/free-game-animations/releases/tag/v1.0)
- Physics reference. River velocity varies across the channel and with depth. Channel slope, depth, and bed roughness influence it. [USGS river velocities](https://pubs.usgs.gov/circ/2003/1246/report.pdf)
- Setup reference. SideFX demonstrates a riverbed collider, obstacles, and an upstream emitter with FLIP. Blender's built-in tools and Python API are available in the benchmark. [SideFX river setup](https://www.sidefx.com/docs/houdini/fluid/splashingwater.html)
