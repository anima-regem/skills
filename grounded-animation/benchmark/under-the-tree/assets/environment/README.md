# Optional environment assets

- `oak_bark_diffuse.jpg` and `oak_bark_normal.jpg` are Poly Haven's 1k Jolcham Oak Bark maps. Treat the normal map as non-color and feed it through a Normal Map node. [Jolcham Oak Bark by Charlotte Baglioni, CC0](https://polyhaven.com/a/jolcham_oak_bark_01)
- `grass/grass_medium_01_1k.gltf` is a small real grass tuft with its relative mesh and textures. Import only a few unique clumps and use linked instances where needed. [Grass Medium 01, CC0](https://polyhaven.com/a/grass_medium_01)
- `autumn_meadow_1k.hdr` is an optional lighting or distant field background. Visible plants that respond to the breeze need scene geometry or a separately animated layer. [Autumn Meadow by Sergej Majboroda, CC0](https://polyhaven.com/a/autumn_meadow)
