# Reuse decisions

**Choosing an implementation.** The ECC Search First skill looks in registries, public implementations, and available tools before writing code. Make the search specific enough to return a working part. For example, when adding caption export to an editor, first look for a serializer that accepts the editor's existing cue model or an inexpensive mapping from it. Try the longest cue and a timestamp crossing the one-hour mark. The useful result is a working export from the editor. [ECC's Search First skill](https://github.com/affaan-m/ECC/blob/0765f7a2ca2bd5df214d3aa7ba7e7ac19db8b189/skills/search-first/SKILL.md)

**Adapting a template.** Suppose a field team needs a printable bilingual inspection sheet. A modest editable form with the right fields, script coverage, and page breaks can beat a beautiful PDF whose source is unavailable. Fill a copy with the longest expected labels and print it at the intended size. This applies GOV.UK's advice to trial a candidate on one difficult, representative problem. [GOV.UK purchasing guidance](https://www.gov.uk/guidance/define-your-purchasing-strategy)

**Taking on a dependency.** A demo may solve the visible problem while leaving the team to maintain an unsupported package or carry a large dependency tree. Before adopting it, inspect the owning repository, the release that works with the project's runtime, and the license for the material being shipped. Preserve the required notices when adapting or redistributing it. [OpenSSF evaluation guide](https://best.openssf.org/Concise-Guide-for-Evaluating-Open-Source-Software.html)

**Recognizing a poor fit.** Cloudflare extended NGINX for years. At its scale, connection pooling across workers became a constraint that pushed the team to evaluate forks, alternatives, and eventually its own proxy. Borrow the question behind that decision. Which measured limitation would still exist after the proposed adaptation? [Cloudflare's Pingora engineering account](https://blog.cloudflare.com/how-we-built-pingora-the-proxy-that-connects-cloudflare-to-the-internet/)
