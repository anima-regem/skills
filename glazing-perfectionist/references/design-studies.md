# Design studies

Use the decision behind a precedent when it fits. Each exercise below applies that decision to a different, hypothetical product.

| What the designers did | How to try the principle |
| --- | --- |
| Braille Institute designed Atkinson Hyperlegible around character distinctions for readers with low vision. [Glyph specimens](https://www.brailleinstitute.org/freefont/) | For equipment checkout, set two plausible serial numbers, `BI10O8` and `B1I0O8`, in the current face at label size. Compare another available face if staff could misread them. Verify the winning treatment on a narrow return slip. |
| GitHub Next designed the Monaspace families to share metrics so different voices fit the same code grid. [Interactive type specimen](https://monaspace.githubnext.com/) | In a music rehearsal tool, first lock the alignment between a lyric and its chord. Try alternate treatments for an editor's annotation. Keep the one that readers can distinguish without moving the chord to the wrong syllable. |
| Duolingo tied a character transformation to a streak milestone and carried the image into a share card. [Design team's case study](https://blog.duolingo.com/streak-milestone-design-animation/) | In a film restoration catalog, a matched before-and-after crop could identify a restored frame in the index and the detail view. Show it only where both images document the same frame. |
| IBM Carbon offers fixed heading styles for dense product layouts and fluid styles for more spacious web contexts. [Typography guidance](https://www.carbondesignsystem.com/building-blocks/foundations/typography/type-sets) | In an archive, let the exhibit title breathe on the opening page and become compact in the accession list. Keep its relation to the collection name consistent in both places. |

For an editable example, the Magister specimen in zstvns's Creative Direction skill takes a product distinction, planned versus completed work, and gives it a visual rule. Compare the documented type roles with their use across the actual artifacts.
